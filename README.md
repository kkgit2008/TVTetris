# TVTetris

一款面向 Android TV 的纯 Java 俄罗斯方块游戏，支持 Android 4.2（API 17）及以上系统。

## 功能

- 遥控器方向键操作：左右移动、向下软降、向上旋转。
- OK/确认键开始、暂停和继续游戏。
- 返回键第一次暂停并提示，短时间内再按一次退出。
- 未结束对局自动保存；再次启动时以暂停状态恢复。
- 仅在 Game Over 时写入本局分数，维护本机 Top 20 排行榜。
- 三栏 TV 布局：左侧排行榜、中间游戏区、右侧双方块预览与操作提示。
- 7-bag 随机算法、幽灵落点、等级加速、清行动画和提示音。
- 黑色低亮度背景与带高光、阴影和渐变质感的彩色方块。

## 构建

项目无 AndroidX、Kotlin 或第三方运行时依赖。需要 JDK 17+ 和 Android SDK 35：

```powershell
./gradlew.bat assembleRelease
```

产物位于 `app/build/outputs/apk/release/TVTetris-release-1.0.0.apk`。Release 构建在本地开发阶段使用 Android 默认调试签名，便于直接安装到测试设备；正式发布前请替换为自己的发布签名。

## 操作

| 按键 | 功能 |
| --- | --- |
| OK / Enter | 开始、暂停、继续或在结束后开始新局 |
| 左 / 右 | 移动方块 |
| 下 | 软降 |
| 上 | 顺时针旋转 |
| 返回 | 第一次暂停并提示，2 秒内再次按下退出 |
